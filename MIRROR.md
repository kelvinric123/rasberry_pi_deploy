# QMed Raspberry Pi deploy mirror

DO NOT EDIT FILES IN THIS REPOSITORY.

It is a generated mirror of qmed4.0/raspberry_pi_v2.1 in the main QMed
repository. Every run of update_raspi_deploy.bat wipes this tree and
re-copies that folder, so anything edited here is lost on the next run.

Edit the scripts in the main repository, then run the .bat again from
there. The copy of the .bat in this repo is a mirrored artifact.

The QMed server clones this repo when an admin presses "Sync" on
https://v2.qmed.asia/admin/raspberry-pi. See README.md for what each
script does.
